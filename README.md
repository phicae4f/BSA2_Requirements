# BSA 02: Анализ требований

## Описание проекта
Проект направлен на освоение этапов работы бизнес и системного-аналитика: переход от текущего состояния системы (as is) к будущему (to be), определение границ системы и описание потоков данных.

В рамках работы прорабатывались требования для двух бизнес-задач: системы онлайн-записи для сети барбершопов и онлайн-сервиса доставки заказов.

## Выполненные задачи

### 1. Анализ текущего состояния (as is)
Составлена таблица ролей и их действий в текущем состоянии (до внедрения системы). Выявлены и зафиксированы ключевые проблемы пользователей.
**Артефакт:** `ex00_<префикс>_asis.xlsx`

### 2. Построение контекстной диаграммы
Разработана контекстная диаграмма, описывающая связи системы с внешним сущностями (пользователи, партнеры, смежные системы) и потоки данных (входящие и исходящие).
**Артефакт:** `ex01_<префикс>_context.png`

### 3. Проектирование будущего состояния (to be)
Таблица ролей дополнена состоянием to be. Для каждой выявленной ранее проблемы предложено решение с учетом внедрения IT-системы.
**Артефакт:** `ex02_<префикс>_tobe.xlsx`

### 4. Проверка потоков данных
На основе контекстной диаграммы построена таблица входных и выходных потоков данных.
**Артефакт:** `ex03_<префикс>_streams.xlsx`

### 5. Актуализация артефактов
Глоссарий проекта дополнен новыми методологическими терминами. Каталог стейкхолдеров актуализирован с учетом новых ролей, выявленных в процессе моделирования.
**Артефакт:** `ex04_<префикс>_glossary.xlsx`


## Стек и инструменты
* **MS Excel** (таблицы действий, потоков данных, глоссарии)
* **MS PowerPoint** (построение контекстной диаграммы)
